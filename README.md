# 광역버스 빈자리 수집기

[광역버스 빈자리 예보](https://binjari.pages.dev)의 실측 자료를 모으는 저장소입니다.

평일 출근(06:00~09:00)·퇴근(17:30~19:30) 시간에 3분 간격으로 두 가지를 기록합니다.
- **노선 단위**(`collect.py`): `active.json`의 노선마다 운행 중 모든 버스의 현재 정류장과 **남은 좌석** 
- **정류장 단위**(`collect_stops.py`): `stops.json`의 주요 정류장(출근 경기 125곳, 퇴근 서울 55곳)에 곧 도착하는
  광역버스 다음 두 대의 **남은 좌석** 
- 출처: 공공데이터포털 「경기도_버스위치정보 조회」, 「경기도_버스도착정보 조회」 (경기도)
- 수집이 계속 실패하면(시작 10분 전 시험 조회 실패, 또는 약 12분 연속 실패) 기록을 저장하고 새 실행 컴퓨터로 자동으로 다시 시작합니다(최대 5번). 실패 이유는 `*_errors.json`에 남습니다.
- 노선 목록: `routes.json` (2026-10-10 경기도 노선조회 API 기준)

노선·정류장·남은 좌석 정보만 다루며 개인정보와 차량번호는 저장하지 않습니다.

이 저장소에는 수집 코드만 있습니다. 수집 기록은 별도 비공개 저장소에 보관하며, 서비스에는 통계로 가공해 제공합니다.
